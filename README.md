# StatMentor AI

StatMentor AI is a guided web application for doctoral researchers that keeps supported statistics inside the app. It provides a scaffolded tour, pilot navigation, data health checks, internal descriptives/correlation/regression computation, recommendations, diagnostics, APA-style reporting, visualizations, and a tutor panel.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
